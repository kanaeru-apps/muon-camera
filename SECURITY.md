# Security Policy

## Supported version

Security updates are applied to the current App Store version and the default
branch. Older TestFlight builds are not supported after a replacement build is
available.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. If
that is unavailable, contact `support.kanaeru@gmail.com` with the subject
`ZERO Camera security report`.

Do not attach private photos, videos, precise locations, credentials, signing
files, or other personal data. Provide the app version, iOS version, affected
feature, and minimal reproduction steps instead.

The maintainer will acknowledge a report within 7 days, assess its severity,
and coordinate disclosure after a fix is available.
